# 客服、支付交互与构建来源检查

## 本次变更

- 客服初始化只读已有会话，首次发送才创建；默认收件箱排除空会话与已结束咨询，支持历史和分段显示。
- 客户端结束咨询收起记录；长对话按需展开，账号变化沿用原有清理机制。
- 工单使用独立站内模态弹窗，客户与原订单始终可核对，关闭后保留同页草稿。
- 工单弹窗不联动展开资料抽屉，键盘焦点在弹窗内循环，关闭后返回原入口；弹窗遮住聊天时暂停推进已读。
- 未修改的订单编辑器不会被当作草稿冻结旧版本；真实编辑继续保留打开时的版本，后台刷新保留售后草稿。
- 套餐价格与时长跟随商品目录；金额用十进制定点解析。退款上限包含待处理退款，类型切换隔离隐藏字段。
- 中文管理后台指向中文客服入口；新增流程支持六语言，结构化客服错误按页面语言显示。
- 退出失败提示明确要求重试，不声称已清理的草稿仍然存在；保留原会话撤销重试和跨页退出边界。
