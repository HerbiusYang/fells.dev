# 客服前端验收记录（2026-10-08）

分支：`codex/online-support`。范围为普通用户客服窗口、私密客服工作台、后端接口预留及仓库外本地模拟环境。

## 新功能与修复

- 客户入口和聊天窗口显示客服在线、离线可留言或状态确认中。工作台每 10 秒续租，租约 45 秒到期；多页签独立，退出撤销租约，断网或异常响应不沿用旧在线状态。状态变化不清除草稿或阻止留言。
- 修复客服入口遮挡原页面发送按钮、短横屏输入区超出屏幕、长名字横向溢出和小字对比度不足；移动端主要按钮至少 44px。
- 会话切换、返回列表、资料抽屉和图片查看器恢复正确键盘焦点；抽屉限制焦点范围，图片按钮被新消息刷新替换后仍能恢复焦点。
- 丢弃早于本地发送确认的慢刷新快照，避免消息暂时消失；清除过时的排队输入通知。客服响应返回后复验会话，已退出的窗口不会因晚失败重新显示。
- 拒绝稀疏消息数组、乱序时间、超出历史的已读游标以及超出会话总量的写入；失败保持原记录与草稿。

## 本地模拟环境

模拟后端及其数据仍位于项目仓库之外。已修复开发服务器经 `/@fs` 读取会话文件、备份和日志的问题，并拦截 Astro 文件插件绕过 Vite 拒绝规则的路径。检查覆盖原始导入、编码、目录穿越、大小写和真实路径；浏览器仅可读取四个模拟适配模块。后台接口仍要求相应角色 Cookie。

已按本轮唯一标记删除测试生成的账号和会话，保留原有本地用户、聊天记录和其他会话；清理前备份仅保存在模拟目录内。模拟服务已重新启动。

## 上线边界

已发现的问题均已修复，以上已测范围未再出现失败；测试不能证明所有未知问题都不存在。当前预览及模拟登录没有真实身份认证。生产上线仍需接入真实后端，验证客服身份、逐会话/附件权限、CSRF、限流与服务器完整图片解码，并补真实 API 和 Firefox 联测。接口和要求见 [后端契约](./online-support.md)。
