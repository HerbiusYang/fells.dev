# Fells 前端真实后端接入（2026-10-09）

## 当前入口

只打开 [Fells 前端](http://127.0.0.1:4321/zh/app/start)。前端分支 `codex/backend-connection`，后端分支 `codex/frontend-integration`（独立工作树 `fells-api-integration`）。用户业务由后端 API 提供：`/portal/` 页面、专用 HTML 及其资源路由已删除，原地址返回 404，后端首页的旧用户入口也已清理。原有管理员运维和 CLI 认证保留。未推送、未部署。

开发代理保留浏览器 Host/Origin，把 `/api/app/`、`/api/support/` 与 `/v1/` 转到本机后端；生产静态托管也需配置同源代理。本轮保留原有布局、样式、导航与主要交互，数据改为由真实服务器读取和保存；业务规则按后端现有人民币钱包、独立美元 API 额度和订阅实施。

## 已连接的流程

| 前端入口 | 当前行为 |
| --- | --- |
| 登录、注册、重置 | 真实密码/邮箱验证码与服务器 Cookie；邮件未配置时明确不可用 |
| 资料、头像、主题、偏好 | 用户范围的服务器保存，刷新后可读取 |
| API Key | 服务器签发；完整值仅创建时显示；实际列表、撤销和单 Key 月限额编辑 |
| 用量与调用记录 | 用户范围真实记录；7 天、30 天、本月查询；费用和调用标价分别展示 |
| 账务 | 人民币现金、人民币赠金、美元 API 额度分别展示；模型/订阅列表来自服务器 |
| Checkout | 充值草稿→付款核对→审核入账；购买订阅或兑换额度是另一步确认操作 |
| 交易重试 | 同一确认请求使用稳定操作 Key；结果不确定时不自动改金额或再次扣款 |
| 订阅价格 | 确认最高人民币扣款在购买事务持锁后校验，价格上涨超上限则整笔回滚并重新确认 |
| 工作区和聊天 | 创建、重命名、删除、用户指令保存、显式 JSON 历史导入与导出 |
| 工作区成员 | 真实 owner/editor/viewer，owner 可添加已存在用户名/验证邮箱或移除成员；人数由真实名单计算 |
| 推荐与条款 | 当前推荐规则、返佣、协议正文及接受记录来自服务器 |
| 在线客服 | 独立操作员认证、文字/私有图片、已读、输入、在线租约、解决/重开、SSE 实时更新 |

## 尚未具备的外部服务

当前还没有 Lody。云电脑、环境变量、Agent 代码执行、工作区文件/画布/站点、插件和用户定时任务保留原入口并显示服务尚未配置。聊天内容保存不等于执行；显式导入历史保留 imported 元数据，Agent 历史显示导入标记，不是新执行结果。

本地没有真实模型上游、邮件发送、收款渠道和在售订阅配置，API 额度销售也未开启。对应目录/商品为空或交易入口禁用；没有模拟支付成功、额度到账或任务完成。静态营销页的旧 Token Plan、credits、CDK、淘宝/闲鱼和价格只是设计数据，不能替代服务器商品。

## 深测与修复

- 旧页绑定真实用户与签名 Cookie 指纹；换账号、同账号重新登录、退出后，旧页不能修改或退出新会话。
- 工作区和聊天操作重新读取真实权限；禁止普通保存伪造 Agent 消息。历史导入必须由用户明确上传确认；共享对话显示服务器记录的作者，导入历史有独立标记。
- 多条历史导入部分失败时显示已保存数量、重新读取服务器结果；后续正常写入仍可继续。
- 请求失败不显示成功，聊天草稿保留；资料/Key 活动不造成无关永久冲突。
- IndexedDB/localStorage/sessionStorage 被禁用时仍可使用真实业务；当前工作区在同会话内保持正确。
- 后台读取不打断已打开菜单/对话框或正在填写的资料表单，提示保留至原显示时间结束；成员计数和 API 时间范围来自正确数据。
- Token 合计按协议处理缓存：OpenAI/Gemini 的 input 已含缓存，Anthropic 的缓存另外计入；1h 缓存写入子集不重复相加。
- 充值获批后读取最新人民币余额；余额刷新失败保留已获批结果，禁止重复付款确认。
- 客服关闭页签释放上游 SSE 连接；独立退出互不影响客户/客服会话。

## 账号入口补充修复

- 注册填写实际登录账号，邮箱验证码验证联系人；资料姓名保持独立。账号格式为 3–32 位小写字母、数字、下划线或连字符，冲突不会覆盖既有账户。
- 服务条款使用独立弹窗，支持关闭、Escape、焦点循环及返回触发按钮；明确按界面语言请求当前服务器条款，安全转为正文，不展示原始标签或执行其中代码。后端条款目前提供中文及英文，其余界面语言使用英文正文。
- 桌面端固定左侧区域，右侧长表单独立滚动；切换登录、注册和密码重置保持左侧位置。六种语言的窄屏布局也有浏览器回归。
- 邮件配置状态通过 `email_enabled` 返回；未配置时禁用验证码发送与注册/重置提交，已有账号仍可登录。本地尚未配置发件账户、Token、发件地址及注册开关，本轮未发送真实邮件。
- 用户自助注册、管理端创建与 GitHub 注册共享身份事务锁，防止并发创建产生大小写或跨账号/邮箱/手机号的登录冲突；账号冲突保留既有唯一性错误分类。
