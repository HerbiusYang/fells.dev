## 快速开始

新用户入口为 `/zh/app/start`（中文）或 `/app/start`（英文）：登录/注册 → 可跳过的偏好问答 → 创建工作区 → 创建并保存第一段对话。新建和对话页面明确提示，当前只保存文本与 API/账户数据，不会在 Fells 内运行 Agent。

## 尚需服务端或运营配置

- 配置邮件和注册开关后，注册及密码重置才能实际发码。
- 配置模型上游、在售商品、收款和开票后，相关按钮才会进入完整业务流程。
- 产品 CDK 交付与通知投递目前没有后端实现；界面未宣称其可用。
- 85 已部署静态前端、同源 API 代理和安全响应头。当前仅开放 HTTP 80；ACME 的 HTTP-01 与 TLS-ALPN-01 验证均从签发端连接超时，443 暂未开放服务。HTTPS Cookie/Origin 登录链路尚未验证；在签发可信证书前，不应通过该 HTTP 地址登录或提交付款信息。
