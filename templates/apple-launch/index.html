Fells 工作区

Claude Code、Codex 等 Agent 共用一个云端工作区。文件、上下文和进度都会保留，关掉电脑它也接着干。

进一步了解

按量付费

其他所有模型，用多少 token 付多少。和 Token Plan 用同一个账号、同一个 Key。

即将推出

亲密好拍档

设置两个环境变量，终端里的工作流一点不变。原来怎么用 Claude Code，现在还怎么用，只是不再掐着 5 小时窗口干活。

怎么接入

在云端工作区里直接用你的额度。电脑、平板、手机，换台设备接着聊，Agent 的进度一直都在。

了解工作区

我们把一份官方 Claude Max 20× 拆成若干席位。每个 5 小时窗口和每周限额里，属于你的那份只归你，别的席位用不到4。

¥99 体验比较所有套餐
  1. 官方价指同等额度按 Anthropic API 公开标价计算的金额，按 1 美元 = 7 元人民币折算。Token Plan 3500：$3,500 额度官方价约 ¥24,500；Token Plan 1500：$1,500 额度官方价约 ¥10,500；体验包：$100 额度官方价约 ¥700。折扣为套餐价与官方价之比，四舍五入。
  2. 保障额度随时可用。超出保障额度后，只要容量有空闲就可以继续使用，直到每月最高可用额度。额度每月重置，不结转。
  3. 体验包仅限新用户购买一次，额度自开通起 30 天内有效。
  4. 拼团席位是一份官方 Claude Max 20× 订阅的一部分，用量跟随官方订阅的 5 小时窗口和每周限额，并按席位大小分配。席位大小与价格将在开团时公布。“没有 5 小时限制”适用于 Token Plan 和体验包，不适用于拼团。

套餐尚未开售，购买入口目前会登记你的邮箱，开售时通知你。价格与规则以开售时的购买页为准。
