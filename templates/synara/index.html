Product questions

Understand the boundary before you run the work.

How agents, subscriptions, parallel tasks, handoffs, Git and the local workspace fit together.

What is Product?

A desktop workspace that runs the coding agents you already use, side by side, with each task keeping its own environment, processes and review state.

Does it include models or need another subscription?

Neither. Each agent uses its own account and models. Product orchestrates them and does not resell access.

What must be installed first?

Git and at least one supported agent CLI, signed in. Product detects installed agents on first launch.

Can several agents work at the same time?

Yes. Each task runs in its own worktree, so parallel agents never edit the same checkout.

Can I switch agents without starting over?

Yes. Handoff keeps the task, working tree and a summary of prior context, then continues with the agent you pick.

How does it fit Git and pull requests?

Review the diff, run checks, commit, push and open a pull request from the task, using your normal remote and credentials.

Does it upload my code?

No. Code stays on your machine and in your Git remote. Agents send to their own providers only what they normally would.
